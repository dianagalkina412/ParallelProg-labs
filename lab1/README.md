# Lab1
Лабораторная работа №1
Написать программу на языке C++ для перемножения двух квадратных матриц.
Исходные данные: файл(ы) содержащие значения исходных матриц.
Выходные данные: файл со значениями результирующей матрицы, время выполнения, объем задачи и др.
Обязательна автоматизированная верификация результатов вычислений с помощью сторонних библиотек или стороннего ПО (например, на Python).

Порядок выполнения л/р:
1. Создание и отладка программы.
Создана программа, которая:
а) генерирует две квадратные матрицы заранее заданного размера из случайных действительных чисел (тип double) и сохраняет их в два csv-файла "MatrixA.csv" и "MatrixB.csv"; если данные файлы уже есть в каталоге программы, то читает значения из них в соответствующие матрицы;
б) выполняет перемножение матриц друг на друга 10 раз; время продолжительности каждой попытки фиксируется и определяется среднее значение продолжительности перемножения матриц; информация о продолжительности каждой попытки и среднем времени выводится на экран, а также сохраняется в файл "Duration.txt";
в) результат перемножения матриц (результирующая матрица) сохраняется в файле "MatrixC.csv".
Создан Python-скрипт, который читает файлы "MatrixA.csv", "MatrixB.csv", "MatrixC.csv"в матрицы NumPy, а затем выполняет сравнение результата перемножения матриц A и B с загруженной матрицей C с точнстью до atol=1e-8.

2. Исследование программы (определение зависимости времени выполнения от объема задачи).
Объём задачи определяется параметрами матриц A(m x n) и B(n x k): O(m x n x k). Для квадратных матриц (n x n) объём задачи O(N^3).
Для определения зависимости времени перемножения от размера матрицы (N) и объёма задачи (N^3) генерировались матрицы с размером N = 25, 50, 75, 100, 125, 150, 175, 200 и снимались показания о среднем времени выполнения. Результаты запусков сохранены в каталогах 25x25, 50x50, 75x75, 100x100, 125x125, 150x150, 175x175, 200x200 и сведены в таблицу (Duration.xlsx), по которым построены графики зависимости времени выполнения от размера матрицы (N) и объёма задачи (N^3).

Вывод.
В результате проведённого эксперимента установлена зависимость времени, затраченного на перемножение двух квадратных матриц, от размера этих матриц (N) и объёма задачи (N^3). Как видно из построенных графиков (Duration.xlsx), для размера матриц зависимость экспоненциальная, а для объёма задачи почти линейная.
